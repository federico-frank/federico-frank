### Hallo, ich bin Federico

Ich studiere Informatik (B.Sc.) an der FernUniversität in Hagen, aktuell im 3. Semester,
und suche eine Werkstudentenstelle in der Backend-Entwicklung mit Cloud-Bezug.

Neben dem Studium baue ich als Hobbyprojekt eine Plattform, über die Kunden regionale Betriebe finden
und mit ihnen in Kontakt treten können. Mir geht es vor allem darum, Konzepte aus dem Studium praktisch
anzuwenden und Themen aufzugreifen, die mich darüber hinaus interessieren:

| Thema | Umsetzung im Projekt |
|---|---|
| Kommunikation über Events | Teilbereiche der Anwendung tauschen sich nur über Events aus (RabbitMQ); die Suche baut daraus ein eigenes Lesemodell auf (CQRS-Ansatz) |
| Asynchrone Verarbeitung | Hochgeladene Logos sind sofort sichtbar und werden im Hintergrund verkleinert und in S3 gespeichert, mit Wiederholungen und Dead-Letter-Queue bei Fehlern |
| Infrastruktur als Code | Die AWS-Umgebung (Netzwerk, Server, Datenbank, Speicher) komplett mit Terraform, bewusst kostengünstig aufgebaut |
| Monitoring | Ereignisse aus der Anwendung als Metriken in Prometheus, ausgewertet in Grafana |

Womit ich arbeite: Java · Spring Boot · PostgreSQL/PostGIS · RabbitMQ · AWS (EC2, RDS, S3) · Terraform · Docker · Prometheus/Grafana · Thymeleaf/HTMX
